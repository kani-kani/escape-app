# １枚絵謎解きスタンドアローンアプリ

[デモサイトを見る（GitHub Pages）](https://kani-kani.github.io/escape-app/)

## 概要
ブラウザ上で完結した謎解きアプリです
問題追加はCSVへカラム追加が必要です

## 主な機能
- １枚絵の謎解きに挑戦できます
- 外部接続がないスタンドアローンアプリです

## 使い方
1. １枚絵による謎が表示されるので、これらを解いてきます

## 開発について
- 制作期間：2日
- sandbox的に作成したアプリケーションです


- 謎について気が向いたら追加、作成します。

## 更新方法

> $ npm run build

にてビルド

> $ npm run deploy

にてデプロイ。GitHubActionにてパイプライン自動実行される
