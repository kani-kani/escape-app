# 20. 外部仕様

## 1. 画面構成


1. 画面構成および画面遷移

本アプリケーションは、以下の画面構成および遷移をベースに構築されています。各問題画面はすべて同一の構成（共通コンポーネント）を用いて表示されます。
[アクセス時] ログイン画面 ──(ログイン)──> メイン画面（問題選択） ──(選択)──> 各問題画面

1.1. ログイン画面

• アクセス時初期表示： アプリケーションアクセス時に最初に表示される画面です。
• メイン画面への遷移： ログイン処理を行うことで、メイン画面へ遷移します。

1.2. メイン画面（問題選択）

• 問題選択エリア： 出題される問題の一覧が表示され、ユーザーが任意の問題を選択して各問題画面へ遷移できます。

1.3. 各問題画面（共通構成）

各問題は、一貫して以下の要素で構成されます。
• 問題表示エリア
	• 謎解き問題（画像またはテキスト）が表示される領域。
• ヒントエリア（ドロップダウンリスト）
	• クリックして展開することで、ヒントが段階的（小出し）に表示される領域。
	• ※ヒントを展開（閲覧）しなくても、解答の入力・判定は可能です。
• 解答入力エリア
	• ユーザーが答えを入力するためのテキストボックス。
• 操作・判定エリア
	• 「判定ボタン」：入力された解答の正誤をチェックするボタン。
	• 「解説ボタン」：問題の解説を表示するためのボタン。
• 解説・結果表示エリア
	• 判定結果や、問題の解説が表示される領域。

2. 操作フローとシステム挙動


2.1. 解答の判定（「判定ボタン」押下時）

ユーザーが解答を入力し、「判定ボタン」を押下した際の挙動は以下の通りです。
• 【正解の場合】
	• 正解判定となり、問題の下部に「解説」が自動的に表示されます。
• 【誤答（不正解）の場合】
	• 誤答判定となります。解説は表示されず、再度解答を入力することが可能です。

2.2. 解説の強制表示（「解説ボタン」押下時）

ユーザーが正解に到達する前に「解説ボタン」を押下した際の挙動です。
• 解答欄のグレーアウト： 解答入力エリアが非活性（グレーアウト）となり、以降の入力ができなくなります。
• 解説の表示： 画面上に問題の解説が表示されます。

3. 動作環境および制限事項

GitHub Pages上で動作するスタンドアロン型（ブラウザ単体動作）の特性上、以下の仕様・制限を持っています。
• 対応ブラウザ
	• 主要なモダンブラウザ（Google Chrome, Apple Safari, Microsoft Edge）の最新版。
• データの非保持（スタンドアロン仕様）
	• サーバーサイドのデータベースや、ブラウザのローカルストレージ（LocalStorage等）によるデータ保存は行いません。
	• ログイン状態、問題の選択状況、回答の進捗、入力途中のテキストなどは保持されません。
• リロード（F5）時の挙動
	• ページの更新（F5等）を行った場合、すべての状態がリセットされ、初期状態（ログイン画面）に戻ります。
